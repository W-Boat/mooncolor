# moonflow

月读的底栏与开书遮罩增强，原名 Moon Color。当前版本 **3.1.0**。配色直接跟随月读官方主题；没有自定义着色引擎，也没有阅读工具箱。

## 安装和更新

从 [最新 Release](https://github.com/W-Boat/mooncolor/releases/latest) 下载 ZIP，将其中的 `mooncolor.koplugin` 放进 KOReader 的 `plugins`，与月读插件同级。

界面名称已经改为 **moonflow**。安装目录 `mooncolor.koplugin`、扩展 ID `ext.mooncolor` 和更新仓库保留兼容，旧版可直接更新，底栏及更新设置继续沿用。请勿同时安装另一份改名文件夹。

**2.x 手动升级请用新文件夹替换旧文件夹，并完全重启 KOReader。** 自动更新通过目录替换清理旧模块。仅覆盖文件不会加载旧着色模块，但会留下旧文件；旧的运行时适配必须重启才能撤销。

设置入口：**月读 → 设置 → 桌面 → moonflow**。颜色、色板和彩色渲染仍在月读官方显示设置中调整。

## 开书遮罩

默认“封面优先 / 一言回退”：

1. 读取月读的书名、作者与本地封面；支持月读身份、章节书及衍生版，缺元数据时回退到文档属性/文件名。
2. 有真实封面时显示真实封面；不生成假封面，不额外打开文档提取图片，也不下载图片。
3. 无封面或图片解码失败时，使用月读 `online.hitokoto:current()` 的有效缓存；没有缓存或已过期时，使用月读 `fallback()` 提供的离线句。
4. 一言连同来源居中显示，书名、作者与真实进度仍保留。每次开书只取一次，不调用 fetch / ensure，不等网络、不在进度更新时换句。

另有“简洁进度”：只显示书名、作者与进度，跳过封面查找/解码和一言读取。

同一次开书只创建一份布局。初始遮罩已画好时，0% 和微小变化不重绘；后续通常至少间隔 1 秒、变化 5% 才刷新进度区域。100% 可及时显示，重复或倒退回调不反复绘制。不虚构百分比，不做动画，不加周期任务。

换书、旋转和样式改变会重建正确布局；完成、出错、密码输入、休眠、停用和退出时释放资源。后续重排保留 KOReader 原生进度行为。没有进度回调的引擎只显示打开界面。

## 底栏

- 桌面与阅读侧栏可分别选择胶囊或短线、显示/隐藏文字、普通/紧凑布局。
- 未单独配置侧栏时沿用桌面偏好。紧凑模式降低高度并缩小图标，显示更多内容。
- 图标模式长按仍显示名称；点当前标签不重复切换，单元宽度不丢尾部像素。
- 颜色使用官方主题接口，不覆盖 Theme.current / BlitBuffer。官方显式隐藏文字设置仍优先。

侧栏布局通过公开 render 方法限定作用范围；未加载侧栏时不主动加载它，不修改内部函数上值。

## 自动更新

默认已联网时每天最多检查一次，并自动下载安装包、核对 SHA-256；**确认后才安装并重启**。不主动开启 Wi-Fi，不周期轮询。目录替换前校验所有运行模块，保留备份并在失败时回滚。更新流程使用月读 HTTP、镜像、worker 与主题组件，以及 KOReader Restart 事件。

## 范围与验证

只保留底栏、遮罩和更新功能。已删除旧着色、调色盘、个人主题、网纹、快捷面板、封面调参、活动环、小票和蓝牙轮询接管。工具箱、插件聚合、相关菜单、快捷面板与手势入口不包含在本版。

基于 Moon 提交 `033b6a3777f4d35a22e0a4d435b41960f2ef156b`：56 项 LuaJIT 回归；Moon 0.2.43 灰度兼容：47 项；28 项浏览器布局预览检查。含真实 Moon 一言缓存/离线回退逻辑验证，以及封面优先、损坏图片回退、一次取句、侧栏上下文恢复和更新回滚检查。

字体、设备、ReaderUI/ReaderRolling、网络和文件系统有边界桩，浏览器字体为近似渲染。没有 Kobo 实机耗时、耗电、色域和刷新波形测量。插件不加速文档解析，也不修改设备驱动。

测试说明见 `tests/README.md`。GPL-3.0-or-later。
