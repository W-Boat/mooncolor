# Moon Color · 底栏与开书遮罩

当前版本 **3.0.0**。月读已支持彩色主题，本插件只保留底栏布局和全屏开书遮罩；配色完全使用月读官方主题。仓库、插件目录和扩展 ID 保持不变，可从 2.x 更新。

## 安装与升级

从 [最新 Release](https://github.com/W-Boat/mooncolor/releases/latest) 下载 ZIP，将其中的 `mooncolor.koplugin` 放入 KOReader 的 `plugins` 目录，与月读同级。

**从 2.x 手动升级时，用新文件夹替换旧 `mooncolor.koplugin`，然后完全重启 KOReader。** 自动更新会通过目录替换移除旧模块。仅覆盖文件虽然不再加载旧着色模块，仍会留下旧文件；运行中的旧适配也必须重启才能撤销。

设置入口：**月读 → 设置 → 桌面 → 底栏与开书遮罩**。主题色、色板和彩色屏幕设置请使用月读官方显示设置。

## 保留的功能

- 底栏：胶囊高亮或短线指示；可隐藏文字，长按图标查看名称；未选中的标签才触发切换；保留点击锚点与准确单元宽度。
- 开书遮罩：全屏显示月读书名、作者和本地封面，缺封面时复用月读生成封面。只读取本地/已缓存图片，不联网，不额外提取文档封面。
- 更新：已有网络时每天最多检查一次，默认自动下载并校验 SHA-256，确认后才安装和重启。保留失败回滚；不会主动开启 Wi-Fi。

## 移除的功能

删除自定义着色引擎、角色颜色、调色盘、个人主题编辑，以及首页/统计/图书馆/侧栏/输入框/分割线的着色适配。不再修改 Theme.current、BlitBuffer、主题 Box、UIManager 刷新或 Moon 内部函数上值。

旧网纹、快捷面板缓存、封面调参、活动环缓存、小票缓存和蓝牙轮询接管一并移除。月读原生菜单、数据、封面加载与休眠逻辑保持官方实现。旧插件配置中的颜色字段不再读取，官方配置不受影响；原有底栏样式、文字开关、开书遮罩与更新设置继续沿用。

## 开书性能

同一次开书共用一份布局、元数据和封面。初始遮罩已经绘制时，0% 和极小变化不重复刷新；后续通常至少间隔 1 秒且变化 5% 才更新进度区域。真实 100% 可及时显示；缓存写入的倒退进度不反复重绘。不会虚构进度，不加动画或周期刷新。

新书和屏幕旋转不继承旧遮罩的节流与尺寸。出错、密码输入、阅读就绪、关闭文档、休眠、停用或退出时释放资源。已渲染文档的后续重排与无进度回调的引擎保留原生行为；没有回调时只显示打开界面。

遮罩不加速文档解析，也不解决设备驱动的休眠问题。

## 验证

原生彩色实现基于 Moon 源码提交 `033b6a3777f4d35a22e0a4d435b41960f2ef156b` 验证；同时检查旧版月读的灰度兼容。测试使用真实 Moon 主题、控件和遮罩代码，字体、设备、ReaderUI/ReaderRolling、网络和文件系统使用边界桩。没有 Kobo 实机耗时、色域或波形测量。

更新与安装继续复用月读异步 HTTP、镜像、worker、主题组件和 KOReader Restart 事件。插件目录替换前校验全部运行模块，失败保留原版或回滚。

开发测试见 `tests/README.md`。GPL-3.0-or-later。
