# Moon Color · 彩墨界面 2.0.0

月读 https://github.com/AnkioTomas/moon 的扩展插件，面向 Kobo Libra Colour / Kaleido 彩墨屏。

## 安装与升级

解压安装包，将 mooncolor.koplugin 文件夹覆盖到 KOReader/plugins，完全退出并重启 KOReader。与月读同级，避免双层目录。需要启用月读「界面显示 → 彩色屏幕支持」。

设置入口：月读 → 设置 → 桌面 → 彩墨界面。

首次升级自动关闭旧版「彩色质量刷新」；新版名称为「强制彩色全刷」，默认关闭。默认开启「快速面板」。建议保持这两个默认值。

## 性能修复

- 缓存配色配置，绘制时不再反复创建配置表和调用 getSource。
- 默认保留原刷新请求，不自动将大区域 ui 刷新升级为 full。
- 快速面板跳过弹窗、侧栏及阅读顶栏的逐像素网纹遮罩，取消网纹引起的强制全刷。不改写月读保存的网纹设置，关闭快速面板或总开关即可恢复。
- RGB 画布代理复用，矩形绘制不再每次创建参数表。
- 活动环使用最多 512×512 的 RGBA 位图缓存；进度、配色、主题或尺寸变化时重建，控件释放时释放位图。

此扩展未重写扩展列表的数据加载。如果第三方扩展有同步网络或数据库操作，仍可能出现等待。

## 颜色与主题

- 单色：深海蓝、松石绿、赤陶红。
- 混色：极光（蓝绿橙）、花园（绿紫红）、日落（红蓝金）。不同界面部位使用不同颜色，无动画渐变。
- 「按部位自定义颜色」支持九组颜色：按钮、图标、标题与数字、导航、进度与角标、统计主色/外环、第二色/中环、第三色/内环、边框。输入 #RRGGBB 或 #RGB。
- 主按钮和进度角标自动选择黑字或白字。
- 「保存当前主题」「我的主题」支持保存、应用、删除，最多 12 套；包含颜色、底栏样式、文字与配色开关，性能设置不跟随主题切换。
- 补齐首页独立热力图、小卡圆点与柱形、同心活动环，保留统计页图表、书架角标、图标、标题及控件配色。
- 底栏支持胶囊或短线，可隐藏文字；隐藏后长按显示名称，整格可点击。
- 白底与正文保持中性灰度；夜间、黑白屏或关闭彩色渲染时回到灰度。

修改颜色或应用主题时清屏一次；平常打开面板不强制全刷。残影明显时可点击「手动清除残影」。

## 修复记录

### 未发布

- 修复书架封面进度角标重着色时的崩溃（月读 0.2.43 / KOReader 2026.07.2，Kobo Monza）：
  `mooncolor_decor.lua` 的 `textColor()` 用 `w.fgcolor ~= nil` 判断控件是否已着色。
  KOReader 的颜色是用 `ffi.metatype` 注册的 cdata，其 `__eq` 元方法会解引用另一个操作数
  （`ffi/blitbuffer.lua` 的 `ColorRGB32_mt:__eq` → `color:getColorRGB32()`），而 LuaJIT 在
  `color == nil`、`color == 数字` 这类比较里同样会调用该元方法，于是抛出
  `attempt to index local 'color' (a nil value)`。现在改为先用 `type()` 判断类型，
  用真值判断“是否已着色”，并用 `sameColor()` 比较两个颜色，不再把颜色和 nil / 数字直接比较。
  同一文件里图标、标题与统计柱形三处同样的写法已一并修正。

## 配置与移除

配置与主题保存在月读数据目录 settings/ext.mooncolor.lua。覆盖升级保留配置。关闭总开关后重开窗口，或移除 mooncolor.koplugin 并重启 KOReader，即可恢复原有界面。

不修改电子书、正文排版、设备退出、蓝牙或 Wi-Fi。使用局部内部接口适配，上游更改可能需要更新。全局 Blitbuffer.Color8 保持不变，原始主题数据不被改写。
