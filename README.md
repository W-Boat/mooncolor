# Moon Color · 彩墨界面

月读的非书源扩展插件，面向 Kobo Libra Colour 等彩墨设备。当前版本 **2.2.0**。

## 安装

从 [最新 Release](https://github.com/W-Boat/mooncolor/releases/latest) 下载 ZIP。解压得到 mooncolor.koplugin，放入 KOReader 的 plugins 目录，与月读 book.koplugin / moon.koplugin 同级；升级时覆盖，完全重启 KOReader。不要形成双层目录。

需要月读开启「界面显示 → 彩色屏幕支持」。

入口：**月读 → 设置 → 桌面 → 彩墨界面**。该页底部显示版本与「检查更新」，复用月读异步网络请求、超时和主题界面。检查只在点击时发起；发现更新后可扫码下载覆盖升级，不自动替换正在运行的插件。

## 配色

- 12 套主题：深海蓝、松石绿、赤陶红、极光、花园、日落、北境、樱花、竹影、薰衣草、琥珀、浆果。
- 九组可独立编辑的颜色；30 色触控调色盘和精确 #RGB / #RRGGBB 输入；最多保存 12 套个人主题。
- 按钮、图标、标题与数字、进度、书架角标、三色活动环、首页热力图与小卡配色。
- 底栏支持胶囊或短线、隐藏文字；首页分页圆点、图书馆顶部标签、输入框焦点、月读分割线、侧栏内容配色。
- 白底、正文保持中性。主按钮文字按底色选黑/白；夜间、黑白屏或关闭彩色渲染时恢复灰度。
- 边框与分割线复用「卡片与弹窗边框」颜色，输入框复用按钮色，侧栏文字复用图标色。

## 性能

默认开启快速面板、快速票根、快速首页，关闭强制彩色全刷与封面缓存增强。升级会一次性撤销 2.1 的激进封面配置；必须完整重启 KOReader。

快速面板跳过逐像素网纹及其触发的全刷，保留月读原设置。封面始终使用月读原生的 50ms 解码批次与 100ms 让出等待，不改写队列、不逐张增加定时任务。默认保留月读 6MiB 缓存，可选增强仅把上限提高到 12MiB。已加载封面按上游逻辑复用与失效，单张解码仍不能中途抢占。

首页短时复用统计结果，在统计变化、日期/范围变化、重新激活时清理。活动环跨控件复用位图，缓存最多 8 张且不超过 4MiB，仍在显示的图片不会提前释放。票根内容不变时复用 PNG，文件、文本、色值、尺寸变化时重新生成。不会跳过不同内容的首次渲染。

全屏开书界面居中显示封面、月读书名与作者。身份信息来自月读 Store.identityFor，支持章节书与衍生版；查不到时回退文档属性/文件名。只显示本地或已缓存封面，不联网、不再次打开电子书提取封面；无封面复用月读生成封面。

同一次开书共用一份布局和封面，不在引擎回调中重复解码。crengine 使用真实读取/排版进度，至少间隔 1 秒且变化 5% 才刷新进度区域；结束、错误、密码、退出和休眠时清理。无进度回调的引擎只显示准备状态。此界面不加速引擎本身的文件解析。

休眠时暂停已有的月读蓝牙状态显示轮询，停止插件绘制和开书进度，恢复后仅重启仍有订阅的原轮询一次。不会打开/关闭蓝牙或 Wi-Fi，不改写内核休眠逻辑。此前日志中的内核拒绝休眠与严重待机掉电仍需实机内核日志诊断，本版没有声称修复驱动问题。

所有优化均有开关，可逐一关闭进行实机对照。更改颜色时清屏一次；平常切换不强制全刷。残影可点「手动清除残影」。

## 兼容与验证

对月读 **0.2.43、0.2.45** 分别运行 110 项 LuaJIT 回归。目标 KOReader **2026.07 系列**。内部适配检查方法与上游源码来源；接口不符时跳过对应适配，避免改写陌生版本。

测试使用真实月读控件、首页、图书馆、侧栏和图片队列，以及 KOReader 的 LineWidget / BottomContainer。数据、文件、设备、字体、ReaderUI/ReaderRolling 接口使用边界桩；含真实 FFI __eq 崩溃回归。开发预览不模拟彩墨色域、刷新波形和残影。

尚未连接 Kobo 实机验证开书全流程、实际耗时、残影及耗电；不能承诺所有延迟均已消除。开书界面可独立关闭。主页、封面和第三方插件的数据/网络开销仍受月读和设备影响。

配置保存在月读数据目录 settings/ext.mooncolor.lua，覆盖升级保留。不更改电子书、正文排版、蓝牙、Wi-Fi 或设备退出。完全移除插件并重启即撤销运行时适配。

## 开发

回归测试需要 Python、lupa，以及月读和 KOReader 源码。见 tests/README.md。新增控件在构造阶段着色，避免每帧扫描；不要全局替换 Blitbuffer 或 KOReader 控件。
